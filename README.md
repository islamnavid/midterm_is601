
# Enhanced Calculator Command-Line Application

## Project Overview

This project is an enhanced Python calculator developed for the IS601 Midterm Project.

The application will support arithmetic operations through a command-line interface (REPL), calculation history, undo/redo, logging, and CSV-based data persistence.

## Planned Features

- Basic and advanced arithmetic operations
- Factory Design Pattern for operations
- Memento Design Pattern for undo/redo
- Observer Design Pattern for logging and auto-save
- Calculation history using pandas
- Environment-based configuration
- Input validation and error handling
- Automated testing using pytest
- GitHub Actions for continuous integration
- Color-coded terminal output

## Installation

Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```
